# Pulse for Windows v0.1.5

继续修复透明区域挡住点击的问题（#30）。v0.1.4 修正了面板和卡片的点击范围，但面板隐藏后再显示，仍可能一直挡住下面应用的按钮。本次修复了这条遗漏的路径。

### 修复

- 面板隐藏后再显示，会恢复“让点击穿过透明区域”的设置。
- 程序会检查窗口的实际状态。即使 Windows 把相关设置冲掉，也会自动恢复，不需要先把鼠标移进面板再移出来。
- 可见的面板栏和详细卡片继续接收点击，透明区域让点击落到下面的应用。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.5_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.5_x64-setup.exe.sig` | 应用内更新使用的安装程序签名 |
| `latest.json` | 应用内更新读取的版本信息 |
| `Pulse_0.1.5_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 升级

已安装 v0.1.3 或 v0.1.4：在 设置 → 关于 点击“检查更新”，按提示安装 v0.1.5。也可以直接下载并运行安装程序。更早版本请手动运行安装程序一次。

问题反馈：[GitHub Issues](https://github.com/FHfanshu/Pulse-Windows/issues)。如果透明区域仍挡住点击，请在 #30 补充截图和触发步骤。
