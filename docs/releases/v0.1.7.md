# Pulse for Windows v0.1.7

修复 Pulse 运行一两天后会突然退出的问题。

### 修复

- Pulse 不再自己退出（#40）。v0.1.5 和 v0.1.6 运行十几个小时到几天后可能直接消失，远程桌面或 UU 远程断开再连回来后更容易遇到。原因是刷新额度后更新托盘图标时，多个后台线程同时操作了只能在一个线程上用的托盘对象，内存被破坏后程序就崩溃了。现在托盘图标、提示文字和托盘菜单都只在界面线程更新。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.7_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.7_x64-setup.exe.sig` | 应用内更新使用的安装程序签名 |
| `latest.json` | 应用内更新读取的版本信息 |
| `Pulse_0.1.7_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 升级

已安装 v0.1.1 或更新版本：在 设置 → 关于 点击“检查更新”，按提示安装 v0.1.7。也可以直接下载并运行安装程序。v0.1.0 请手动运行安装程序一次。

### 已知限制

- 这个问题平均一到三天才出现一次，修复是根据崩溃转储分析得出的，还需要实际使用几天来确认不再出现。
