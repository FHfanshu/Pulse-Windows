# Pulse for Windows v0.1.4

修复完全透明的面板区域仍会拦截底层应用点击的问题，并新增“额度用尽时保持圆环填满”选项，让倒计时中的耗尽额度可以按真实剩余显示。面板透明的边距现在让点击穿透到后面的应用；关闭新选项后，耗尽的圆环会按真实剩余绘制，直到 0%，并在轨道上保留暗红提示。

### 修复与改进

- 面板窗口只在可见的面板栏与详细卡片轮廓上接收点击，完全透明的边距不再挡住在它后面的应用（#30）。面板栏与卡片之间的空隙继续保持可悬停。轮廓判定随光标采样周期（激活时 16 ms）更新，紧贴边缘时仍可能有极短的延迟。
- 设置 → 圆环与数字 新增“Keep ring filled when exhausted”（额度用尽时保持圆环填满），默认开启，与上游一致：耗尽的额度在倒计时期间仍画成满环（#29）。关闭后，倒计时按真实剩余绘制，可以一直减少到 0%；此时空环保留暗红色轨道提示，避免丢失警示。主环、环内的次环、托盘圆环与 dashboard 的绘制规则都与该选项保持一致；“已消耗”模式不受影响。
- 旧设置的默认行为不变：升级后该开关保持开启，显示效果与 v0.1.3 相同。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.4_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.4_x64-setup.exe.sig` | 安装程序的更新签名（应用内更新使用） |
| `latest.json` | 应用内更新读取的版本信息 |
| `Pulse_0.1.4_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 升级

已安装 v0.1.3：在 设置 → 关于 点击“检查更新”，然后按提示安装 v0.1.4。应用会静默安装并自动重启。更早版本请先手动运行安装程序一次。

### 已知限制

- 本版本仍处于早期阶段；构建与自动化测试通过不代表所有服务都完成真实账号验证。
- Token 统计取决于工具实际保存的日志和 Windows 路径，缺失记录可能导致统计不完整。
- 费用为估算值，不是服务商账单。
- 当前只提供 Windows x64 发行文件，未配置代码签名，可能出现 SmartScreen 提示。更新包有独立的更新签名，应用只会安装用内置公钥验证通过的更新。
- 免安装 ZIP 版本也能检查更新，但点击“更新”会运行安装程序，把 Pulse 安装到用户目录，而不是替换 ZIP 内的文件。
