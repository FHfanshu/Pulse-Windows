# Pulse for Windows v0.1.3

修复在不同高度的详细卡片之间快速切换时，指向三角跳动或反向漂移的问题。卡片位置、高度与指向位置现在使用协调的几何关系；屏幕放不下卡片时，内容仍在卡片轮廓内滚动，真实毛玻璃效果保持可用。

### 修复与改进

- 在 Codex 高卡片与 OpenCode 矮卡片之间快速切换时，卡片及其指向三角不再跳动或反向漂移。
- 卡片位置、高度与指向位置按协调的几何关系更新，指向保持对齐。
- 保留屏幕边界内滚动与真实毛玻璃背景。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.3_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.3_x64-setup.exe.sig` | 安装程序的更新签名（应用内更新使用） |
| `latest.json` | 应用内更新读取的版本信息 |
| `Pulse_0.1.3_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 升级

已安装 v0.1.2：在 设置 → 关于 点击“检查更新”，然后按提示安装 v0.1.3。应用会静默安装并自动重启。更早版本请先手动运行安装程序一次。

### 已知限制

- 本版本仍处于早期阶段；构建与自动化测试通过不代表所有服务都完成真实账号验证。
- Token 统计取决于工具实际保存的日志和 Windows 路径，缺失记录可能导致统计不完整。
- 费用为估算值，不是服务商账单。
- 当前只提供 Windows x64 发行文件，未配置代码签名，可能出现 SmartScreen 提示。更新包有独立的更新签名，应用只会安装用内置公钥验证通过的更新。
- 免安装 ZIP 版本也能检查更新，但点击“更新”会运行安装程序，把 Pulse 安装到用户目录，而不是替换 ZIP 内的文件。
