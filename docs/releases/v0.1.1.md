## Pulse for Windows v0.1.1

在 v0.1.0 的基础上加入应用内更新，并修复面板的若干显示与卡死问题。

### 新增

- **应用内更新**：设置 → 关于 显示当前版本和更新状态，可点击“检查更新”；发现新版本后点击“更新到 X”即可。应用在后台下载安装包并校验签名，以只有进度条的静默方式安装（当前用户安装，无需管理员权限），完成后 Pulse 自动重新启动，不再需要点过安装向导。
- “自动检查”默认开启，每两小时检查一次；只提示，不会自行安装。发现新版本时，托盘菜单顶部也会出现“Pulse X 可更新”。
- 设置 → 关于 补全了数据来源、源代码地址与致谢（含上游 [qunqin24/Pulse](https://github.com/qunqin24/Pulse)）。
- 面板的真实毛玻璃：开启“玻璃”后，横条、贴边的底座和详细卡片都会模糊其后方的真实桌面，边缘与形状完全贴合。系统关闭“透明效果”或在远程桌面中时，自动回到按窗口取色的玻璃。
- 面板在贴边与悬浮之间切换、横竖转向时有过渡动画。

### 修复与改进

- 开机自启现在是静默的：登录后只出现面板和托盘图标，不会弹出设置或服务选择窗口。
- 登录项指向的路径与当前安装不一致时（例如旧的安装位置）会在启动时自动指回当前的 Pulse；在 Windows 设置 → 应用 → 启动 或任务管理器中关闭 Pulse 后，设置里的“登录时启动”开关会同步为关闭。
- 修复面板拖动、动画期间窗口可能“未响应”的卡死。
- 修复详细卡片的指向箭头与卡片之间多出的一道内部边线。
- 开发时 `npm run tauri:dev` 会自动选择空闲端口，多个检出同时开发不再互相占用。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.1_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.1_x64-setup.exe.sig` | 安装程序的更新签名（应用内更新使用） |
| `latest.json` | 应用内更新读取的版本信息 |
| `Pulse_0.1.1_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 升级

v0.1.0 没有内置更新，请先手动运行 `Pulse_0.1.1_x64-setup.exe` 安装一次（覆盖安装，设置与凭据保留）；此后的版本可直接在 设置 → 关于 更新。

### 已知限制

- 本版本仍处于早期阶段；构建与自动化测试通过不代表所有服务都完成真实账号验证。
- Token 统计取决于工具实际保存的日志和 Windows 路径，缺失记录可能导致统计不完整。
- 费用为估算值，不是服务商账单；缺少模型价格时无法可靠估价。
- 当前只提供 Windows x64 发行文件，未配置代码签名，可能出现 SmartScreen 提示。更新包有独立的更新签名，应用只会安装用内置公钥验证通过的更新。
- 应用内更新的完整流程（下载、安装、重启）需在 v0.1.1 发布后、由 v0.1.1 更新到下一个版本时才能实际走通。
- 免安装 ZIP 版本也能检查更新，但点击“更新”会运行安装程序，把 Pulse 安装到用户目录，而不是替换 ZIP 内的文件。
