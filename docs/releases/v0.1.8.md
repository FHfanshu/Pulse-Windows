# Pulse for Windows v0.1.8

修复远程连接后侧栏看不见的问题，让设置里几个原本不起作用的选项生效，并新增 KohakuTerrarium 的 Token 统计。

### 修复

- 远程桌面或 UU 远程进出后，停靠的侧栏有时看不见，需要关掉再打开“显示浮动面板”才能恢复（#41）。现在 Pulse 会按手动切换的方式自动恢复：先隐藏，稍等片刻再显示，并在远程画面恢复后再补做一次。
- 应用内更新安装前会先移除托盘图标，不再在任务栏通知区域留下一个失效的图标（#42）。

### 设置生效

- **预测**（圆环与数字 › 预测）：卡片的每个限额下方会显示预计用完的时间，例如“约 30 分钟后用完”“撑不到本窗口结束”或“预计可以撑到窗口结束”（#43）。
- **数字在圆环旁**：顶部浮动横条打开百分比时，可以把数字放在圆环右侧（#43）。
- **自动收起**：停靠时侧栏收成屏幕边缘的一条细条，鼠标移到边缘时展开，移开后收回；浮动时不收起（#44）。
- **停靠时显示警示颜色**：收起后的细条会按额度状态显示警示颜色（#44）。

### 新增

- Token 统计支持 KohakuTerrarium（kt），读取 `%USERPROFILE%\.kohakuterrarium\sessions` 中的会话（#45）。kt 未记录模型名称的调用只计 Token，不估算费用；其他机器同步过来的 `mirror` 会话不计入本机。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.8_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.8_x64-setup.exe.sig` | 应用内更新使用的安装程序签名 |
| `latest.json` | 应用内更新读取的版本信息 |
| `Pulse_0.1.8_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 升级

已安装 v0.1.1 或更新版本：在 设置 → 关于 点击“检查更新”，按提示安装 v0.1.8。也可以直接下载并运行安装程序。v0.1.0 请手动运行安装程序一次。

### 已知限制

- 远程恢复（#41）在开发环境中验证过，真实的远程桌面和 UU 远程断开、重连还需要实际使用确认。
- “自动收起”默认仍为关闭（上游默认开启），需要在设置中手动打开。
