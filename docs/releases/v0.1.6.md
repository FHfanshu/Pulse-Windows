# Pulse for Windows v0.1.6

修复刷新时一直转圈的问题，发现新版本时会弹出通知，远程桌面回来后浮窗会自动恢复。另外，圆环默认显示 5 小时限额，添加的 Claude / Codex 账号也能显示估算价值。

### 修复

- 刷新额度不再一直转圈（#37）。单个账号的刷新最多等 60 秒，超时后保留上次的读数并标为过期；出错或中断后转圈也会停止，刷新按钮恢复可用。每个账号开始和结束刷新时都会更新显示，不用等其他账号。
- 从远程桌面或串流软件回到本机后，浮窗不再消失（#38）。解锁、重新连接、显示器或分辨率变化后会自动重新显示；虚拟显示器暂时不可用时不再崩溃。

### 改进

- 启动 20 秒后自动检查更新（#36）。发现新版本时会弹出一次 Windows 通知，点击打开 设置 → 关于 进行更新。同一版本只提醒一次；更新仍需你点击才会安装。开机自启时如果网络还没连上，10 分钟后会再试，不用等两个小时。
- 在 Pulse 里添加的 Claude / Codex 账号也能显示估算价值（#28）。条件是本机 CLI 当前登录的就是这个账号，并且从这个额度窗口开始时就是它；判断依据是账号的用户 ID 和组织/工作区 ID，不看名字或邮箱。这些 ID 只留在内存里，Pulse 记录登录变化时只保存哈希。默认账号的估算方式不变。刚升级或刚切换本机登录后，当前窗口可能暂时没有估算，下一个窗口开始后会显示。
- 圆环默认显示 5 小时限额。同时有多条 5 小时限额时，优先显示不分模型的那条。没有 5 小时限额的账号仍显示用量最高的一条。第二个圆环仍显示其余限额中用量最高的一条，所以周限额也看得到。在 设置 → 账号 → “圆环显示” 中固定某条限额后，按固定的显示。

| `Pulse_0.1.6_x64-setup.exe.sig` | 应用内更新使用的安装程序签名 |

### 升级

已安装 v0.1.1 或更新版本：在 设置 → 关于 点击“检查更新”，按提示安装 v0.1.6。也可以直接下载并运行安装程序。v0.1.0 请手动运行安装程序一次。

### 已知限制

- 远程桌面和串流软件回到本机后的浮窗恢复，只用自动化测试模拟了 Windows 的会话和显示器消息，还没有在真实的远程桌面或 UU 远程中测过。
- 添加账号的估算价值只用测试数据验证过，还没有用真实的多个账号测过。
