## Pulse for Windows v0.1.0

首个 Windows 公开预览版本：将 [qunqin24/Pulse](https://github.com/qunqin24/Pulse) 的 AI 编程额度监控体验移植到 Windows 10 / 11。

### 功能

- 屏幕边缘额度圆环与悬停详情，展示各额度窗口及重置时间。
- Windows 托盘、设置、快捷键、面板位置与显示选项。
- 接入 Claude Code、Codex、Cursor、GitHub Copilot 等 20 个额度服务；实际可用信息取决于账号权限与认证方式。
- 本机 Token 记录聚合，按工具、模型、日期、项目和会话分析消耗，提供可用价格下的费用估算与使用回顾。
- 工具删除旧日志后仍保留已统计的历史用量（Claude Code、Codex 及其他本机记录）。
- 面板可选黑色或浅色；云母效果用桌面壁纸的色彩为面板着色（与 Windows 任务栏一致），并可开启闪粉。
- 详细卡片显示本机近 31 天用量、主力模型与缓存命中率。
- 简体中文、繁體中文、英文、日文与韩文界面，安装程序跟随系统语言。
- 使用 Windows DPAPI 保护 Pulse 保存的凭据。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.0_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.0_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 已知限制

- 本版本仍处于早期阶段；构建与自动化测试通过不代表所有服务都完成真实账号验证。
- Token 统计取决于工具实际保存的日志和 Windows 路径，缺失记录可能导致统计不完整。
- 费用为估算值，不是服务商账单；缺少模型价格时无法可靠估价。
- 当前只提供 Windows x64 发行文件，未配置代码签名，可能出现 SmartScreen 提示。
- 应用内自动更新尚未接入，请通过 GitHub Releases 手动下载新版本。

问题反馈：[GitHub Issues](https://github.com/FHfanshu/Pulse-Windows/issues)。请提供 Windows 版本、复现步骤和脱敏日志。
