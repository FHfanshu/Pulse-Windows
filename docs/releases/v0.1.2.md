## Pulse for Windows v0.1.2

修复面板在贴边、切换卡片和小屏幕上的若干显示问题。这是第一个可以从 v0.1.1 直接在应用内更新的版本。

### 修复与改进

- 贴靠到屏幕边缘或从边缘拖出后，面板不再跳动或闪一下；窗口位置与变形动画沿同一条弹簧曲线移动。
- 快速在圆环之间切换卡片时，毛玻璃背景不再偶尔消失一帧。
- 屏幕放不下详细卡片时（小屏幕或高缩放），卡片限制在可见范围内，内容在卡片轮廓内滚动，不再被截断。
- 启动时偶尔读不到设置、面板按默认尺寸显示导致卡片被截断的问题已修复。
- Claude 卡片右上角的套餐名显示为 “Pro”，不再显示 “default”。
- 圆环下方的百分比改用 Outfit 字体（字重 500，等宽数字）。
- 开发版与正式版分开使用数据目录和应用标识，可以同时运行。

### 下载

| 文件 | 用途 |
| --- | --- |
| `Pulse_0.1.2_x64-setup.exe` | Windows x64 安装程序，推荐使用 |
| `Pulse_0.1.2_x64-setup.exe.sig` | 安装程序的更新签名（应用内更新使用） |
| `latest.json` | 应用内更新读取的版本信息 |
| `Pulse_0.1.2_windows-x64.zip` | 解压后运行 `pulse.exe` 的免安装包 |
| `SHA256SUMS.txt` | 安装包与 ZIP 的 SHA-256 校验表 |

需要 Microsoft Edge WebView2 Runtime。设置、凭据及缓存位于 `%APPDATA%\Pulse`。

### 升级

已安装 v0.1.1：在 设置 → 关于 点击“更新到 0.1.2”即可，应用会静默安装并自动重启。v0.1.0 请先手动运行安装程序一次。

### 已知限制

- 本版本仍处于早期阶段；构建与自动化测试通过不代表所有服务都完成真实账号验证。
- Token 统计取决于工具实际保存的日志和 Windows 路径，缺失记录可能导致统计不完整。
- 费用为估算值，不是服务商账单。
- 当前只提供 Windows x64 发行文件，未配置代码签名，可能出现 SmartScreen 提示。更新包有独立的更新签名，应用只会安装用内置公钥验证通过的更新。
- 免安装 ZIP 版本也能检查更新，但点击“更新”会运行安装程序，把 Pulse 安装到用户目录，而不是替换 ZIP 内的文件。
